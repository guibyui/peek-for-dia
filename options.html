Blank Window

A light, tabbed window without the profile sidebar. Open one with the shortcut below, or right-click the toolbar icon → New Blank Window.

Shortcut …

Works whenever a web page or a Blank Window is focused. Click Change, then press the new keys (include Ctrl, Option/Alt or ⌘). Esc cancels.

Want one that also works on Dia's new tab page or when Dia isn't in front? Set it on the browser's shortcuts page: open shortcuts page . Browsers don't accept Ctrl+Option combos there.

  • ⌘/Ctrl + T new tab · ⌘/Ctrl + W close · ⌘/Ctrl + L address
  • ⌘/Ctrl + S hide sidebar · ⌘/Ctrl + Shift + O send tab to Dia

Copy URL without Dia's extra message

With a peek open, Dia's own ⌘⇧C also flashes "Copied Current URL" on the page behind it. To have only the peek's message:

  1. In Dia → Settings → Shortcuts, clear Copy URL (and Copy URL as Markdown if you use it).
  2. Open the extensions shortcuts page and set Peek's Copy current URL to ⌘⇧C (and the Markdown one to ⌥⇧⌘C).

Peek then handles ⌘⇧C everywhere: the peeked page when a peek is open, the current tab in a Blank Window, and the normal tab otherwise, with one "Copied Current URL" pill.
